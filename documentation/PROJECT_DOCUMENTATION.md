# Hyper Local Service Provider - Complete Project Documentation

## 1. Project Overview
**Project Name:** Hyper Local Service Provider
**Purpose:** A web-based marketplace connecting customers with local service providers (SPs) for home services (e.g., Cleaning, Repair, Beauty, etc.).
**Platform Revenue Model:** The platform earns a **5% Commission** on every service booked, included in the final bill.

## 2. Technology Stack
*   **Backend:** PHP (Native)
*   **Database:** MySQL
*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 4
*   **Server:** XAMPP (Apache)

## 4. Workflows

### How a Booking Works (End-to-End)
1.  **Customer** browses services and adds a "Sofa Cleaning" (Rs. 1000) to Cart.
2.  **System** adds 5% Platform Fee (Rs. 50).
3.  **Customer** confirms Order Total: **Rs. 1050**.
4.  **Customer** chooses "Cash On Delivery" and places order.
5.  **Service Provider** receives the order in their Dashboard.
6.  **Admin** Dashboard updates Revenue by **Rs. 50**.
7.  **Service Provider** delivers service and collects **Rs. 1050**.
    *   *Note:* SP keeps Rs. 1000 and owes Rs. 50 to the Platform (settled offline/weekly).
